Instalar Claude Code y usarlo por primera vez

Hoy dejamos la máquina lista y le pedimos la primera tarea de verdad. Vamos parte por parte, sin apuro, y nadie avanza hasta que al de al lado le funcione. Si no estuviste en la Sesión 1, no importa: esta sesión arranca desde cero.

Si ya lo instalaste la semana pasada: no te aburras — la segunda mitad de la sesión es de uso, y esa es nueva para todos. Aprovecha la primera media hora para ayudar a quien va empezando.

Antes de conectarte

  • Tu computadora encendida — Windows o Mac. Desde el teléfono no se puede.
  • Tu correo abierto, para confirmar la cuenta.
  • Una tarjeta lista para el pago, o hablado ya con Edgar si estás en Venezuela.
  • Papel y lápiz para anotar correo y contraseña.
  • Venezuela: el VPN instalado y probado antes de la sesión, si te da chance.
  • Hora y media libre. Esta sesión no es de escuchar, es de hacer.

Qué vas a lograr hoy

  • Entender qué es Claude Code, la terminal, un prompt y una carpeta de proyecto — sin tecnicismos
  • Cuenta de Claude con plan Pro activo
  • VPN funcionando, para quien está en Venezuela
  • Claude Code instalado y conectado a tu cuenta
  • La carpeta de tu proyecto creada
  • Tu primera tarea real pedida y resuelta por Claude, en tu computadora

La prueba con la que cerramos

Cuando termines la instalación, haz esto tal cual. Si te sale, quedaste lista para la semana:

# 1. Crea la carpeta de tu proyecto y entra
mkdir mi-proyecto
cd mi-proyecto

# 2. Abre Claude ahí adentro
claude

# 3. Ya adentro, escríbele en español:
Crea un archivo hola.txt que diga: Funciona
Si aparece el archivo hola.txt dentro de esa carpeta, terminaste. Manda una captura al grupo para que sepamos que te funcionó.
Los tres errores de siempre: instalaste y no cerraste la terminal (ciérrala y ábrela otra vez) · te conectaste con el correo equivocado (/logout y de nuevo) · abriste claude parada en la carpeta equivocada (/exit, cd a la correcta, y otra vez).

Tarea para la semana

  • Abrir Claude Code al menos tres días distintos, aunque sea cinco minutos. La meta es perderle el miedo a la terminal.
  • Practicar moverte: cd, cd .., dir o ls, y pwd cuando te pierdas.
  • Pedirle a Claude tres cosas de tu proyecto real: una fácil, una mediana, y una que creas que no va a poder.
  • Anotar en un papel las dudas que salgan. Esas las resolvemos en la sesión individual.
