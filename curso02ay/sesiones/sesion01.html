Arrancamos: Claude Code instalado y funcionando

Esta primera sesión es puro montaje. Al final de hoy todos tenemos la cuenta paga, el programa instalado y una prueba que funciona en nuestra propia computadora. Nada de teoría — dejamos la máquina lista para trabajar.

Sábado 11:00 am (Chicago) 12:00 m Venezuela 1:00 pm Argentina 6:00 pm Barcelona Zoom · se graba

Antes de conectarte

  • Tu computadora encendida — no el teléfono. Hoy hay que instalar cosas.
  • Una tarjeta lista para el pago, o hablado ya con Edgar si estás en Venezuela.
  • Acceso a tu correo, para confirmar la cuenta.
  • Papel y lápiz, o un bloc de notas abierto, para anotar correo y contraseña.
  • Hora y media libre. No es una sesión de escuchar, es de hacer.
Nersy y Zenaida: el VPN lo instalamos y lo probamos juntos en la sesión. No tienes que llegar con nada montado — solo con la computadora encendida.

Qué vamos a lograr hoy

  • Cuenta de Claude creada, con plan pago activo (US$20/mes, unos US$22 con impuesto)
  • VPN funcionando — para quien está en Venezuela
  • Claude Code instalado en tu computadora
  • Entender qué es la terminal y manejar 7 comandos básicos
  • Conocer 6 comandos de Claude Code
  • Una prueba real: que Claude cree un archivo en tu máquina

La prueba con la que cerramos

Cuando termines la instalación, haz esto. Si te sale, ya estás lista para la semana:

# 1. Crea una carpeta de prueba y entra en ella
mkdir prueba-ayayai
cd prueba-ayayai

# 2. Abre Claude ahí adentro
claude

# 3. Ya adentro, escríbele en español:
Crea un archivo hola.txt que diga: Funciona
Si aparece el archivo hola.txt dentro de esa carpeta, quedaste lista. Manda una captura al grupo para que sepamos que te funcionó.

Tarea para la semana

  • Abrir Claude Code al menos tres días distintos, aunque sea cinco minutos. La idea es perderle el miedo a la terminal.
  • Crear una carpeta con el nombre de tu proyecto y dejarla lista.
  • Pedirle a Claude una cosa sencilla relacionada con tu proyecto y ver qué pasa.
  • Anotar en un papel las dudas que te salgan. Las resolvemos en la sesión individual.
